## Approved divergences / open items requiring a human decision

- **Music/audio deferred.** No `transit-authority-music.mp3` exists and no audio-generation tool is available in this environment. Plan Slice 1 step 6 flagged this explicitly ("confirm a matching audio file + audioManifest.ts entry actually exists or gets added — new-derelict shipped reusing eden-prime's music key, which reads as a bug, not a pattern to repeat"). Asked the user which of three options to take (wait for a supplied file / temporarily reuse another world's key / leave unbound and adjust the test); got no response within the wait window, so proceeded on best judgment: left `worldMusicManifest["transit-authority"]` unbound rather than reusing another world's key (the plan explicitly calls that an anti-pattern) or unilaterally loosening a shared test file's assertion (out of this plan's scope). `TableScene.startWorldMusic` degrades gracefully when a world has no manifest entry (console.warn, no crash), but `worldAssetBindings.test.ts`'s "musicKey is bound in worldMusicManifest" check for `transit-authority` will keep failing until a real audio file is supplied and wired. **Still the one item blocking a fully green `bun run test`** — needs a human decision (supply a track, or explicitly accept a scoped test exception) before this world is fully PR-ready.
- **No unlock gate — ships free/immediately selectable.** Final validation found that `transit-authority` has no `worldUnlock` entry in `src/data/unlocks/catalog.json`, unlike every world shipped since Eden Prime (all gated). Only the original 3 cycle-1 starter worlds ship ungated today. The spec's Open Question 3 ("ship data-ready but hidden, as allowed for Giants, if world-select capacity is tight") assumed a decision would be made here; the plan's Slice 2 step 5 made adding an unlock-catalog entry conditional on that decision, and it was never resolved — the mechanical result of skipping it is the opposite of "hidden": the world is unlocked and visible to everyone by default. Asked the user (gate it like recent worlds / ship free intentionally / decide later); got no response within the wait window. Did not unilaterally add a gate, since that requires inventing an unlock condition and generating a new unlock-icon asset — a real design decision, not a mechanical fix. Left as-is and flagged loudly here rather than silently accepted. **Needs a human decision before merge**, same category as the music gap.
