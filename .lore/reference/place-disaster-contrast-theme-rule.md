# Place and Disaster Must Argue With Each Other

Every world pitch should pair a place with a catastrophe that argues with it, so the result doesn't quite make sense — and that friction is the point. Named 2026-06-11 during approval of the Overgrown Mall / Fog Beach Party / Whiteout Parking Garage trio, but the shipped worlds already followed it implicitly before it had a name.

## The Rule

A world's fiction should not be "an ordinary place plus a disaster." It should be a place whose ordinary character is in tension with what the disaster does to it:

- **Overgrown Mall** — malls were already declining on a forty-year clock; the infestation just compresses that decay instead of inventing a new one.
- **Whiteout Parking Garage** — parking garages are already emotionally cold, bare concrete; the blizzard makes that literal instead of introducing an unrelated threat.
- **Fog Beach Party** — a beach party is a place built for joy; the Mist rolling in over it reads as meaner for the contrast than the same fog over, say, an already-grim location would.

## Why It Matters

This is a cheap, free-to-apply filter for pitching new worlds: if the place and the disaster agree with each other too neatly (a haunted graveyard has a ghost problem), the pairing is generic. If they argue, the world's identity is stronger before a single card is written. Use this alongside the [[keyword-bias-differentiation]] lever and the signature-verb requirement in [[theme-authoring]] — this rule is about the *pitch*, those are about the *mechanics*.
